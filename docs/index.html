    Pobierz instalator
    
Instalator nie jest podpisany certyfikatem, więc Windows może pokazać okno „System Windows ochronił komputer”.
      Kliknij Więcej informacji → Uruchom mimo to.

  


  
Instalacja

  
    
    
  1. Zamknij GstarCAD (wcześniej uruchom go przynajmniej raz na tym koncie Windows).
    2. 
    
  2. Uruchom pobrany plik TelekomCAD-Setup-….exe — instalacja nie wymaga uprawnień administratora.
    3. 
    
  3. Uruchom GstarCAD — TelekomCAD załaduje się sam (zakładka na wstążce, pasek narzędzi, panel map).
    4. 
  


  
Licencja

  
    
    
  • Przez pierwsze 30 dni program działa bez licencji.
    • 
    
  • Polecenie TCADLICENCJA → Kod kopiuje kod komputera — wyślij go autorowi, a otrzymasz plik licencji.
    • 
    
  • TCADLICENCJA → Wczytaj — wskaż otrzymany plik .lic. Jedna licencja obejmuje 2 komputery.
    • 
    
  • Po zmianie komputera lub ponownej instalacji Windows: TCADLICENCJA → Przeniesienie przygotuje gotową prośbę.
    • 
  


  
Aktualizacje

  
Przy pierwszym uruchomieniu GstarCAD w danym dniu program sprawdza, czy jest nowa wersja, i pyta o zgodę na instalację.
    Nowa wersja działa po ponownym uruchomieniu GstarCAD. Ręcznie: polecenie TCADAKTUALIZUJ.


  
Dziennik (dla testujących)

  
Polecenie TCADLOGI → Folder — wskaż folder Dysku Google / OneDrive udostępniony autorowi. Program będzie tam
    kopiował swój dziennik (bez rysunków). Wylacz zatrzymuje kopiowanie.


  
Prywatność

  
Program nie wysyła danych o użytkowniku. Raz w miesiącu pobiera z tej strony listę odwołanych licencji, a raz dziennie opis
    najnowszej wersji. Mapy pobiera z usług wskazanych w ustawieniach (np. Geoportal).
